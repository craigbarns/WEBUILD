## 2. Analyse concurrentielle (réalisée le 04/09/2026)

- SERPs dominées par des **indépendants locaux** (Berkail, Neos Bâtiment, Renov13, Martel, Kalix…). Agrégateurs (Habitatpresto, Travaux.com) surtout en ads.
- **Berkail** (n°1 « rénovation appartement ») : marque forte, prix au m² publiés, délai garanti avec pénalités, espace client. Faiblesse : rien pour investisseurs.
- **Neos Bâtiment** : 25 ans, pages services + réalisations + FAQ. Faiblesse : générique, pas d'angle investisseur.
- **Renov13** : maillage arrondissements, mentionne bailleurs. Faiblesse : mur de texte SEO, aucune preuve.
- **Kreat'iv** : domine « marchand de biens ». Faiblesse : keyword-stuffing, aucune preuve, crédibilité fragile.
- **GERE** : n°1 « rénovation immeuble », cible investisseurs. Faiblesse : contenu brouillon, pages maigres.

**Opportunités retenues** (intégrées au site) : (1) page investisseurs forte — intention B2B mal servie ; (2) preuve par les réalisations avant/après ; (3) structure technique complète que les concurrents n'ont pas tous ; (4) contenu honnête plutôt que murs de texte SEO. **Différé** : transparence tarifaire (publier des fourchettes €/m² réelles quand WEBUILD aura validé ses chiffres — levier fort, personne de crédible ne le fait bien) ; études de cas investisseurs chiffrées (avec accord clients).

## 3. Google Business Profile — plan complet

- **Catégorie principale** : « Entreprise de rénovation » (Renovation company). Secondaires : « Entrepreneur général », « Électricien », « Plombier », « Service de rénovation de salles de bains », « Magasin de carrelage » NON — rester sur les corps de métier réels uniquement.
- **Nom** : WEBUILD (jamais « WEBUILD Rénovation Marseille Travaux » — spam = suspension).
- **Description** (750 car. max) : entreprise générale de bâtiment à Marseille ; rénovation d'appartements, maisons, immeubles et locaux ; tous corps d'état ; approche dédiée investisseurs/marchands de biens ; visite gratuite, devis sous 48h.
- **Services** : créer un service par corps de métier + « Rénovation pour investisseurs », chacun avec description courte et lien vers la page du site correspondante.
- **Zone desservie** : Marseille (tous arrondissements) + métropole Aix-Marseille. Adresse : [À COMPLÉTER — adresse réelle du siège ; si pas de local recevant du public, configurer en « entreprise de services à domicile » avec adresse masquée].
- **Téléphone** : 07 66 01 88 26 (identique au site — NAP strict).
- **Lien site** : https://webuildmarseille.fr/ — **Lien rendez-vous/devis** : https://webuildmarseille.fr/#contact?utm_source=google&utm_medium=gbp&utm_campaign=devis
- **Photos** : logo, couverture (hero chantier), 10+ photos réelles dès disponibles (équipe, avant/après, outils, camion). Geotag naturel (prises sur place).
- **Posts** : 1/semaine — avancement chantier, avant/après, conseil travaux, temps fort de l'entreprise. Lien vers la page la plus pertinente avec UTM.
- **Q/R** : semer les vraies questions (zone ? devis ? copropriété ? investisseurs ?) avec réponses officielles.
- **Avis** : voir §4. Objectif : 10 avis en 90 jours, puis rythme 2-4/mois. Répondre à 100 % des avis, avec mention naturelle du type de chantier et du quartier quand le client l'évoque.

## 4. Système de collecte d'avis (réels uniquement)

1. À la livraison : remise en main propre + demande orale (« votre avis compte beaucoup pour nous »).
2. J+2 : message WhatsApp/SMS avec le **lien direct d'avis Google** (généré depuis la fiche GBP : « Obtenir plus d'avis »).
3. J+10 : relance unique, légère, si pas d'avis.
4. Inviter (sans dicter) à raconter : type de travaux, quartier, comment s'est passé le suivi. Jamais de consigne de mots-clés, jamais d'incitation contre avis positif (interdit Google).
5. Reprendre les avis Google sur le site (avec accord) pour remplacer les témoignages placeholders actuels.

## 5. Citations locales & backlinks (raisonnable, pas de spam)

Priorité : GBP → PagesJaunes → Houzz → Yelp FR → Apple Plans → Bing Places → annuaires pro sérieux (Societe.com, Vérif, Batiactu si éligible) → fiches partenaires (fournisseurs, architectes, agences immobilières marseillaises avec qui WEBUILD travaille réellement) → presse locale si actualité réelle. NAP strictement identique partout (nom, tél, adresse, URL). Interdits : achat de liens, PBN, annuaires spam, commentaires.

## 6. Plan 90 jours

**Jours 1–7** (fait) : architecture silo 8 pages, SEO technique (canonical, robots, sitemap, 404, JSON-LD, twitter cards), FAQ home, formulaire Netlify, extraction CSS/JS. **Reste cette semaine** : créer la fiche GBP, connecter Search Console + soumettre sitemap, remplacer coordonnées/mentions légales par les données réelles.
**Jours 8–30** : 3-6 vraies réalisations photographiées et publiées (remplacer les visuels IA), pages chantier détaillées (/realisations/[slug]/), création boîte email pro, premiers avis Google, Search Console : corriger couverture/CWV.
**Jours 31–60** : pages services restantes si justifiées (salle de bains, cuisine, électricité, plomberie, locaux) — une par une, avec vrai contenu ; 2 premiers articles du cluster (prix rénovation appartement Marseille avec fourchettes validées par WEBUILD ; rénover pour louer) ; citations §5.
**Jours 61–90** : analyse Search Console (requêtes émergentes), optimisation CTR titles/metas des pages à impressions sans clics, expansion des contenus gagnants, décision pages par arrondissement (uniquement avec contenu réel spécifique : réalisations du quartier, typologie de bâti, contraintes locales).

## 7. KPI & pilotage

Lead qualifié > trafic. Suivi hebdo : demandes de devis (formulaire Netlify), appels, clics WhatsApp (mesurer via UTM/événements). Suivi mensuel Search Console : impressions, clics, CTR, positions par cluster (Rénovation appartement / Immeuble / EGB / Investisseurs / Local / Marque). GBP : appels, demandes d'itinéraire, vues fiche, avis (nombre + note). Objectifs 90 jours : 10 avis Google, 20 requêtes en top 20, 5-10 leads qualifiés/mois, pages 100 % indexées.

## 10. GEO / moteurs génératifs — principes appliqués

Bloc entité autonome en haut de chaque page (qui/quoi/où/pour qui) ; FAQ rédactionnelles avec réponses directes ; structure Hn propre ; JSON-LD cohérent (entité #entreprise réutilisée partout) ; NAP identique site/GBP/annuaires ; llms.txt à la racine (fichier déclaratif, sans pouvoir SEO démontré — simple bonus). Aucun « hack » : la citabilité par ChatGPT/Perplexity/Gemini viendra de la cohérence d'entité + preuves réelles (avis, réalisations) + présence dans les annuaires que ces moteurs lisent.
